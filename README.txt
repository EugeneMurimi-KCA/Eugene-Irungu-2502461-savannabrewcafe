SAVANNA BREW CAFÉ — WEBSITE PROJECT
HTML & CSS Assignment | Student: Irungu Eugene | Admission No: 25/02461

PROJECT PAGES
- index.html       Home page with hero, introduction, featured items and visit call-to-action
- about.html       Café story, founder profile, quotation and three business values
- menu.html        Three semantic menu tables: hot drinks, cold drinks, bakery and snacks
- gallery.html     Eight responsive figure/figcaption image entries
- contact.html     Contact details, opening-hours table and accessible reservation form
- css/style.css    One shared external stylesheet for all five pages
- images/          Local brand logo and original café-themed artwork in JPG and SVG formats

HOW TO VIEW
1. Extract the ZIP file.
2. Open the savanna-brew folder.
3. Double-click index.html, or open it in Chrome, Firefox or Edge.
4. Use the navigation bar to visit all five pages.

IMAGE GUIDELINES
The image resources use the file names and dimensions specified in the assignment:
- logo.png: 200 × 60 px
- hero.jpg: 1600 × 700 px
- about-owner.jpg: 600 × 600 px
- latte.jpg, cappuccino.jpg and croissant.jpg: 400 × 300 px each
- gallery-1.jpg through gallery-8.jpg: 600 × 450 px each
The café illustrations are original artwork created for this Savanna Brew concept, rather than copied screenshots or a generic template. SVG source artwork is included alongside the JPG files for reference. Images use object-fit: cover where appropriate to preserve their proportions.

TECHNICAL NOTES
- The project uses HTML5 and CSS only; no JavaScript framework or external UI library is required.
- Every page links to the shared css/style.css file and has its own title and meta description.
- The layout uses CSS Grid and Flexbox, CSS custom properties, hover/focus states, transitions and responsive breakpoints including 768 px.
- The reservation form uses a mailto action. It can open the visitor's configured email application, but it does not save bookings to a database. A real booking service requires a backend.
- The address, telephone number, email and social details are fictional assignment details.
- Google Fonts are linked externally; fallback fonts are defined in the stylesheet.

VALIDATION BEFORE SUBMISSION
Run each HTML page through https://validator.w3.org/ and the stylesheet through https://jigsaw.w3.org/css-validator/. Correct any errors reported. Do not claim validation has passed until the files have been checked with the validators.
